# Навыки дизайна презентаций

Установлены для этого проекта из официального репозитория [anthropics/skills](https://github.com/anthropics/skills):

- **frontend-design** — композиция, типографика, визуальный стиль и осмысленная анимация HTML-презентации.
- **theme-factory** — десять цветовых и шрифтовых тем, визуальный каталог и руководство по созданию своей темы.

Оба навыка используют лицензию Apache-2.0; файлы лицензий сохранены. Версия источника и контрольные суммы находятся в `SOURCES.json`. Для этих навыков не нужны API-ключи или дополнительные пакеты.

Каталог `.agents/skills` предназначен для навыков проекта. В новой сессии Codex сможет обнаружить их при работе в этом репозитории; правила выбора также записаны в корневом `AGENTS.md`. В текущем сеансе инструкции можно читать напрямую из соответствующих `SKILL.md`.

В этой облачной среде дополнительно доступен встроенный навык PowerPoint: `/opt/codex/skills/builtins/presentations/SKILL.md`. Он не скопирован в репозиторий и зависит от установленного облачного runtime.

Установка не меняет текущие слайды или фирменное оформление EVOLET.
