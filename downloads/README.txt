EVOLET — У доверия есть корни
5 слайдов: выводы четырёх экспериментов о доверии и общий итог.

Основа — качественные наблюдения и выводы, предоставленные командой.
Вымышленные показатели прежней версии удалены. Новые численные результаты не добавлены.

СОДЕРЖАНИЕ
1. Дерево доверия: некоторые ветви остались пустыми. Доверие невозможно построить в одиночку.
2. Вопросы и ответы: ответы сохранены, вопросы изменены, смысл изменился. Доверие особенно важно там, где невозможно всё проверить.
3. Руководитель и замена: передача части функций, свободы решений и ответственности.
4. Доверие и доверчивость: большинство коллег попытались оценить достоверность информации. Доверять — не значит верить всему.
5. Общий вывод: доверие складывается постепенно из участия, ответственности, открытости и поступков. Трудно заслужить. Легко потерять. Важно сохранить.

КАК ОТКРЫТЬ
Распакуйте архив и откройте index.html в браузере.
Презентация автономная: изображения, музыка и шрифты встроены.
Интернет для показа не нужен. Каждый слайд содержит анимацию своего вывода.
Крупные заголовки, контрастные смысловые блоки и диагональные переходы.
PDF и PowerPoint — широкоформатные версии 16:9.
Просмотр кода HTML в GitHub не запускает презентацию. GitHub Pages пока не настроен.

УПРАВЛЕНИЕ
Стрелки / пробел — сменить слайд.
F — полный экран.
N — заметки ведущего.
R — повторить анимацию текущего слайда.
«Пауза / Продолжить» — остановить и продолжить с того же места.
«Фильм» — автопоказ, 75 секунд (1:15).
«Звук» — музыка во время автопоказа.
PDF — печать всех пяти слайдов.

Для живого выступления используйте ручное переключение и presenter_script.md.
Сценарий рассчитан примерно на 3 минуты 40 секунд с паузами.
