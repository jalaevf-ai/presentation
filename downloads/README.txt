EVOLET — У доверия есть корни
6 сцен с итогами недельных экспериментов о честности и доверии.

В начале из лаймовой эмблемы EVOLET вырастает дерево с мощным витым стволом, густой кроной и широкими корнями по присланному образцу. Три ветви: говорить открыто, слушать без осуждения, договариваться ясно. В финале дерево возвращается рядом с фразой «Спасибо, что сказал. Давай разберёмся».

index.html — автономная презентация. Скачайте файл и откройте в браузере.
Автопоказ: 1:36. «Звук» включает музыку при автопоказе.
Ручное управление: стрелки/пробел; F — полный экран; N — текст ведущего.
Все изображения, музыка и шрифты встроены; интернет для показа не нужен.

pravo_na_pravdu_film.mp4 — фильм с музыкой, около минуты, без дикторской озвучки.
pravo_na_pravdu.pdf — 6 страниц для запасного показа.
