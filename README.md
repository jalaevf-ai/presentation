**Все результаты и числовые показатели — демонстрационные.** Реальные данные ещё не добавлены. Изображения созданы как художественные иллюстрации, а не фотографии участников.

## Управление

- **← / → / пробел** — сменить сцену.
- **F** — полный экран.
- **N** — заметки ведущего.
- **«Фильм»** — автопоказ на 1:32.
- **«Звук»** — включить музыку во время автопоказа.
- **PDF** — печать всех сцен.

MP4 содержит музыкальную дорожку без дикторской озвучки. PDF и PowerPoint — запасные варианты без анимации; слайды PowerPoint сохранены изображениями.

## Содержание

1. Право на правду.
2. Тишина не доказывает согласие.
3. Правда бывает неудобной.
4. Доверию нужна ясность: кто, что, когда.
5. Первые сигналы и пределы недельного эксперимента.
6. Доверие начинается с нашей следующей реакции.

Финальная привычка: **«Спасибо, что сказал. Давай разберёмся»**.
