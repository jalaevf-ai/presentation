# Presentation design skills

Use the project-local skills when the task calls for their capabilities:

- `.agents/skills/frontend-design/SKILL.md`: composition, typography, visual identity and purposeful motion for the HTML presentation.
- `.agents/skills/theme-factory/SKILL.md`: color and font systems when choosing or developing a theme. Its ten theme references and showcase are included.

The current EVOLET presentation already has a user-selected brand direction: navy, white and lime, the supplied logo, and the tree growing from its lines. Keep that direction unless the user requests a change. A request to install skills does not authorize a redesign.

For native PowerPoint work, this cloud runtime also includes `/opt/codex/skills/builtins/presentations/SKILL.md`. Read it when working on PPTX, if the file is available. Resolve its bundled resources against `/opt/codex/skills/builtins/presentations/`; examples using `/root/.codex/skills/builtins/` refer to a different runtime layout. Use the HTML design skill for browser slides and SVG animation.

When editing the presentation, preserve the user's supplied conclusions and do not invent measurements. Check the rendered result, keyboard controls, reduced-motion behavior and the exports affected by the change. Keep generated deliverables consistent with `index.html`.

The installed skills retain their upstream licenses. Source revisions and file checksums are recorded in `.agents/skills/SOURCES.json`.
